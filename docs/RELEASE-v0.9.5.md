# v0.9.5 金铲铲D牌助手

## 使用

下载 JccDHelper-v0.9.5.apk，在手机安装后启用“金铲铲D牌助手”的无障碍服务。保存卡组，显示悬浮窗，再由你开启自动拿卡。安装或更新后默认暂停。

图文教程、权限、构建和诊断说明见仓库 README。

## 当前行为

- 搜索中文棋子名，选中后显示带头像与 × 移除的优先级标签，可保存并切换多套卡组。
- 支持自动拿卡与自动刷新两个开关，悬浮输入“刷新留金”。
- 保留金币只限制自动刷新；目标卡只要当前金币足够就买，批量购买不会超支。
- 刷新与购买串行，刷新后等待新商店卡面稳定，旧识别结果作废。
- 原生裁剪随商店水平偏移调整，已验证偏移约 −45 像素的现场布局。

## 适配与已知限制

当前只验证小米 14、2670×1200 原始横屏画面。其他设备或界面比例需要重新标定。尚未实现通用 OCR 模糊纠错和常见错字自动学习；完整卡池准确率和长期实战错买率仍待验证。五张 ≤150ms 仅指输入排程，不含截图、OCR 与画面确认时间。
