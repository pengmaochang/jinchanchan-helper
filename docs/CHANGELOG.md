# 更新记录

## v0.10.0（测试版，第三套导入与预览已实机验证）

- 游戏实测已完成第三套替换和应用；每次导入成功均刷新本地阵容预览，返回助手时重新载入图片。应用后的短暂标题 OCR 波动，可由已核对行的头像图像和“取消”状态共同确认。
- 实机回测：用户确认重新导入后第三套紧凑阵容图已更新，本地预览文件已保存。

- 支持批量阵容码、自动提取名称、复制代码及保留旧手动卡组，上限 200 套。
- 初次未解析阵容在开启拿卡时先导入一次；已解析后不因开启开关反复导入。
- 商店打开时先点总金币收起，再导入剪贴板；收藏满时替换并应用第三套。
- 预览只保留目标行的名称和英雄，排除应用按钮和多余右侧空白，提示遮挡时等待。
- 头像解析与本地缓存；不完整结果需要明确核对确认，导入期间暂停普通买卡/刷新。
- README 顶部增加用途、数据交互和公平竞技免责声明。

## v0.9.5

- 保留金币仅限制自动刷新；购买目标只检查当前实际金币。
- 主界面增加明确说明，悬浮面板字段改为“刷新留金”。
- 增加保留 60 / 现有 11 金币仍购买目标、五费批量不超支的回归。

## v0.9.4

- 刷新与购买手势互斥，派发新动作使旧识别结果失效。
- 刷新后至少等待 350ms、购买后 100ms 再取帧。
- 新商店连续两帧稳定才允许拿卡；自动刷新也要求卡面稳定。
- 不再仅凭金币减少判定刷新完成；回调超时暂停，不自动重放旧动作。
- 批量输入改为 20～26ms 按压、3～5ms 间隔，五张排程 ≤150ms。

## v0.9.3

- 用现场截图确认商店整体约左移 45 像素导致固定区域读偏。
- 水平定位刷新文字，同步调整卡名、费用、金币裁剪与点击位置。
- 原布局、偏移布局和收起商店样本回归通过。

## v0.9.2

- 增加部分字段恢复与有期限的识别缓存。
- 非空但未读出的卡位与真正空位分开处理。
- 增加本地滚动诊断。该版按金币和帧数推断刷新完成的规则已被 v0.9.4 替代。
