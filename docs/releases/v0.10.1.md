# v0.10.1 · 阵容码管理与刷新留金

推荐使用阵容码管理常用阵容：一次添加多套，在悬浮窗切换后导入游戏，再按已确认的英雄名单拿卡。

## 阵容码管理

- 粘贴 `【阵容码】#阵容名称#代码`，自动提取名称，支持批量添加与更新，和手动卡组合计最多 200 套。
- 悬浮窗选择阵容码后复制代码；商店展开时先点总金币收起，再打开阵容、导入代码。
- 收藏已满时替换第三套并应用；原第三套内容会被替换，请将其作为助手切换阵容的位置。
- 首次选中尚未解析的阵容码，开启自动拿卡会先导入一次。已解析阵容不会因为再次开启拿卡而反复导入。
- 每次成功导入更新本地紧凑阵容图，保留名称与英雄，去掉应用按钮和多余空白；返回助手时重新加载。
- 通过头像匹配随包棋子目录生成英雄名单；识别不完整时需补齐并点击“保存并确认英雄名单”。已确认的购买名单在重新导入时保留。

## 刷新留金

快捷档位改为 **0 / 15 / 25 / 35 / 45 / 55 / 85 / 105**。

多留几块钱，方便购买刚刷新出的目标牌。例如选择 55，在保留 50 金币之外预留一张五费卡的预算。

- 留金只限制自动刷新，不限制目标购买；自动刷新需要满足 `当前金币 − 2 ≥ 留金值`。
- 默认值仍为 50，升级保留原设置；可输入 0～999 自定义数值。
- 自定义 50 时，快捷向上到 55、向下到 45，边界不循环。

## 安装与升级

1. 下载本 Release 的 **JccDHelper-v0.10.1.apk**，同签名安装可覆盖旧版，保留本地阵容与设置。
2. 更新后确认系统无障碍服务已启用，再显示悬浮窗。安装过程会停止旧进程，自动拿卡需按需重新开启。
3. `SHA256SUMS.txt` 提供安装包校验值；完整使用说明和实机配图见仓库 README。

本版包含 v0.10.0 阵容码功能；v0.9.5 用户升级后即可使用。README 配图取自 v0.10.0 实机，主体界面与本版一致，最新留金档位以本文为准。
